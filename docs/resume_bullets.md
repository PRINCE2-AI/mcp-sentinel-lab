# Resume Bullets

- Built MCP Sentinel Lab, a runtime security gateway and evaluation bench for
  tool-using AI agents, with MCP manifest scanning, tool pinning, policy
  enforcement, privacy-aware data-flow checks, and SQLite decision traces.
- Implemented deterministic attack simulations for prompt injection, MCP tool
  poisoning, credential exfiltration, workspace escape, memory poisoning, and
  cross-tool data leakage, comparing baseline vs protected agent behavior.
- Added CLI, FastAPI, Streamlit dashboard, OpenRouter/OpenAI optional
  explanations, unit tests, GitHub Actions CI, and recruiter-ready documentation
  mapping the project to AgentDojo, MCPTox, AgentCanary, OWASP MCP Tool
  Poisoning, and SAFE-MCP.
